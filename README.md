# CodeAlpha_EmailExtractor
Task automation script built for the **CodeAlpha Python Programming Internship (Task 3)**.

## What it does
Reads a `.txt` file, extracts every email address using a regex, removes duplicates, and saves them to a new file.

## Concepts used
`re`, file handling, `sys`

## Run
```bash
python email_extractor.py                      # uses sample_input.txt
python email_extractor.py mytext.txt out.txt   # custom files
```
